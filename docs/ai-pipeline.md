# AI pipeline

1. The API validates extension, MIME, file signatures, size, duration, and server-generated storage names. Production audio is stored in S3-compatible object storage and served through short-lived signed URLs.
2. The speech adapter calls multilingual Whisper through `automatic-speech-recognition` with timestamp and detected-language output, explicitly selecting Whisper's `transcribe` task. Timestamped radio therefore remains in the driver's spoken language rather than being translated. The optional text-emotion and English urgency signals are applied only when Whisper identifies English.
3. The audio-emotion adapter loads audio at 16 kHz and evaluates overlapping windows. Raw labels and scores are stored. The default is the generic SUPERB fallback; an external candidate can run only when its signed benchmark manifest verifies its exact revision and calibration artifact.
4. Labels are mapped to `calm`, `stressed`, `tired`, `frustrated`, `urgent`, or `uncertain`.
5. Optional text emotion contributes a small score; urgency keywords contribute a small bounded signal. The audio model remains primary.
6. Sliding audio-classification windows are merged into reportable evidence events before timing metrics are calculated. If the user selected audio-only, no lap comparison is performed. If the user supplied real lap timing, high-stress events are matched only to a lap whose timestamp window contains the event; unmatched events are shown explicitly. That lap and the next supplied lap are compared with the session median without double-counting overlapping windows.
7. Rules generate recommendations, with an explicit “association, not proof of causation” explanation.

The model IDs and timeout are environment variables so the adapters can be changed without rewriting business logic. Analysis runs in a Redis/RQ worker and the API reports queued/running/failed/completed states. Source audio and lap inputs are locked while a job is active, preventing mixed-input reports. A model download failure becomes a retryable job error; it is not replaced by a fabricated normal-user result. Raw outputs, labels, confidence, language, model IDs, calibration version, signed benchmark status, processing version, and timestamps are retained for provenance.
